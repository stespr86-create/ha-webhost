🏠 HA WebHost

Website-Hosting, das so einfach ist, dass es jeder schafft

❓Was ist HA WebHost?

Stell dir vor: Dein Home Assistant läuft 24/7 zuhause. Warum nicht darin auch Websites hosten?

HA WebHost ist ein Add-on für Home Assistant mit dem du:

📝 WordPress-Blogs

Vollständiges WordPress mit Plugins & Themes. Alles im Browser zu installieren.

🖼️ Fotogalerien

Fotos hochladen, mit der Familie teilen – kein Account nötig!

🎨 Statische Websites

HTML/CSS/JavaScript Websites von ZIP-Upload starten.

🚀 Git-Deployment

Code zu GitHub pushen → Website aktualisiert sich automatisch.

💡 Das Wichtigste: Alles funktioniert im Browser. Keine SSH, keine Kommandozeile, keine Server-Admin-Kenntnisse nötig!

👥Passt das zu mir?

✅ Perfekt für dich, wenn du:

  • Ein Home Assistant hast (und es zuhause läuft)
  • Eine einfache Website brauchst (Blog, Portfolio, Galerie)
  • Deine Daten lieber selbst hosten willst statt bei BigTech
  • Mit Tailscale/VPN von überall zugreifen möchtest
  • Nicht viel über Server-Admin wissen willst

❌ Nicht ideal, wenn du:

  • Eine hochperformante Multi-Server-Infrastruktur brauchst
  • Mit Millionen von Besuchern gleichzeitig rechnest
  • Nur Cloud-Lösungen nutzen willst

🚀So funktioniert's (5 Minuten)

Schritt 1: Installation

  1. Home Assistant öffnen → Settings (Zahnrad unten links)
  2. Add-ons → Add-on Store (rechts oben)
  3. Nach "HA WebHost" suchen und auf das Ergebnis klicken
  4. INSTALL klicken und warten (2-3 Minuten)
  5. "Start on Boot" einschalten (wichtig!)
  6. START klicken
  7. OPEN WEB UI klicken → HA WebHost Panel öffnet sich

Schritt 2: Erste Website erstellen

Im HA WebHost Panel hast du mehrere Optionen:

Option A: WordPress-Blog (Das Einfachste)

1. Button "Neue Site: WordPress" klicken
2. Namen eingeben (z.B. "mein-blog")
3. Blog-Titel & Admin-Email angeben
4. "WordPress installieren" klicken
5. 1-2 Minuten warten
6. Link klicken → WordPress-Setup durchlaufen
7. Fertig! Blog läuft 🎉
Option B: Fotogalerie (Super einfach)

1. "Neue Site: Fotogalerie" klicken
2. Namen eingeben (z.B. "hochzeit-2024")
3. Link an Familie/Freunde weitergeben
4. Sie können sofort Fotos hochladen!
5. Deine Daten, auf deinem Server 🔐
Option C: Statische Website (ZIP-Upload)

1. Du hast eine HTML/CSS/JS Website
2. Als ZIP-Datei speichern
3. "Neue Site: ZIP-Upload" → ZIP auswählen
4. Hochladen & warten
5. Website läuft sofort! 🚀

🔧Für Developer (API)

HA WebHost hat eine vollständige REST-API. Damit kannst du alles programmgesteuert machen:

WordPress-Site erstellen (Python):

import requests

response = requests.post(
  "http://ha-server.local/api/sites/wordpress",
  data={
    "name": "mein-projekt",
    "blog_name": "Mein Projekt",
    "admin_email": "ich@example.com"
  }
)

site = response.json()
print(f"Admin: {site['wordpress_admin_user']}")
print(f"Passwort: {site['wordpress_admin_password']}")
Plugin suchen & installieren (cURL):

# Suchen
curl "http://ha-server.local/api/sites/mein-blog/plugins/search?q=backup"

# Installieren
curl -X POST "http://ha-server.local/api/sites/mein-blog/plugins/install" \
  -d "slug=all-in-one-wp-migration&activate=true"
📚 Vollständige API-Dokumentation: In der README.md auf GitHub!

⚡Performance & Limits

Wie viele Websites?

Praktisch: 5-10 WordPress-Sites auf einem normalen Home Assistant problemlos.

Mehr geht auch, braucht aber entsprechend mehr RAM & Speicher.

Wie schnell?

Scenario Performance
Personal Blog (1-10k Besucher/Monat) ✅ Sehr schnell
Business-Website (10-100k Besucher/Monat) ✅ Schnell
Große Community (100k+ Besucher/Monat) ⚠️ Könnte eng werden

Rule of Thumb: Wenn du über 100k Besucher/Monat hast, brauchst du wahrscheinlich einen größeren Server.

❓Häufig gestellte Fragen

F: Brauche ich technische Kenntnisse?

A: Nein! Das Panel ist so gestaltet, dass jeder es nutzen kann. Für erweiterte Sachen (API, Automatisierung) hilft die Dokumentation.

F: Kann ich die Websites von außen erreichen?

A: Ja! Mit mehreren Optionen:

  • 🚀 Tailscale: Einfach, kostenlos, sicher - EMPFOHLEN!
  • 🔒 Wireguard: Sicher, aber manuell
  • ☁️ HA Cloud: Eingebaute HA-Lösung
  • ⚠️ Port-Forwarding: Funktioniert, aber Sicherheitsrisiko

F: Was passiert wenn der Server runterfährt?

A: Das Add-on startet automatisch neu (wenn "Start on Boot" an ist). Deine Daten bleiben erhalten.

F: Wie oft sollte ich Backups machen?

A: Automatisch täglich. Du kannst jederzeit manuell ein Backup erstellen über das Panel.

F: Kann ich meine Websites exportieren?

A: Ja! Über die Backup-Funktion bekommst du ZIP-Dateien mit allen Daten.

F: Welche Plugins funktionieren?

A: Fast alle! Es gibt aber einige Ausnahmen:

  • ❌ Plugins die eigene Server brauchen
  • ❌ Plugins mit PHP-Version-Anforderungen
  • ✅ 99% der Standard-Plugins funktionieren

🌐Von überall zugreifen (Tailscale)

Was ist Tailscale?

Ein sicheres, kostenloses VPN dass du überall nutzen kannst. Dein Home Assistant ist immer erreichbar - egal wo du bist!

Setup (5 Minuten):

  1. Home Assistant SSH Add-on installieren (Settings → Add-ons → Add-on Store → "SSH Server")
  2. SSH öffnen und folgendes eingeben:
    curl -fsSL https://tailscale.com/install.sh | sh
  3. Dann: tailscale up
  4. Den Link öffnen und dich anmelden
  5. Fertig! Dein HA ist jetzt überall erreichbar unter:
    https://dein-ha-name.ts.net:8000
🔒 Super sicher: Selbst dein ISP/Router sieht nicht wo du zugreifst. Nur du und Tailscale!

🐛Probleme? So geht's weiter:

Installation klappt nicht?

  • Hast du genug Speicherplatz? (mindestens 2 GB frei)
  • Ist Home Assistant aktuell? (Settings → Updates prüfen)
  • Netzwerkfehler? (Router neustarten)

WordPress lädt nicht?

  • Add-on neustarten (Settings → Add-ons → HA WebHost → Restart)
  • Warte 30 Sekunden und versuche es erneut
  • Logs anschauen (Settings → Add-ons → HA WebHost → Logs)

Plugin-Installation fehlgeschlagen?

  • Ist das Plugin mit deiner WordPress-Version kompatibel?
  • Versuche ein anderes Plugin von der Such-Liste

Weiterhin Probleme?

✅ Schau auf GitHub Issues: github.com/stespr86-create/ha-webhost/issues

Oder erstelle ein neues Issue mit deinem Problem!
